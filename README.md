# ✈ 飞机大战（手绘风 · 网页版）

一个纯前端实现的竖屏 2D 射击小游戏，素材为铅笔手绘风格，音效与背景音乐由 Web Audio API 实时合成（无需音频素材文件）。

## 运行方式

**方式一（推荐）：直接双击 `index.html`**，用 Chrome / Edge 打开即可，无需安装任何依赖。

**方式二：本地服务器**（可选，效果相同）

```bash
node server.js
# 浏览器打开 http://localhost:8080
```

> 说明：游戏所有素材使用相对路径加载，直接双击即可运行；`server.js` 只是提供一个可选的静态服务。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动飞机 |
| （自动） | 持续向上发射子弹 |
| `空格` | 引爆炸弹（清空全场敌机，需要先拾取炸弹道具） |
| `P` / `Esc` | 暂停 / 继续 |
| `Enter` | 开始游戏 / 重新开始 |
| `M` | 静音 / 恢复声音 |

## 玩法与规则

- 背景持续向下滚动；主角生成于屏幕中下部分，共 **3 点生命**，左下角以图标显示。
- 敌机从屏幕上方出现，向下移动，撞上主角会爆炸并扣 1 点生命（碰撞后 2 秒无敌闪烁）。
- 三种敌机：**小型（enemy1）** 每架 100 分、**中型（enemy2）** 每架 500 分、**大型（enemy3）** 每架 4000 分。
- 子弹默认 `bullet1` 单发连射；拾取 `bullet_supply` 后 30 秒内切换为 `bullet2` 双发并排。
- 拾取 `bomb_supply` 增加炸弹计数，按空格引爆后全场敌机爆炸并计分。
- 生命归零则游戏结束，显示最终得分与历史最高分（保存在浏览器 localStorage），可点击“重新开始”。

## 数值设计（可在 `js/game.js` 顶部集中调整）

| 项目 | 数值 |
| --- | --- |
| 画布尺寸 | 480 × 700（与 background.png 一致） |
| 主角 | 显示尺寸缩小 30%（约 72×89），移动速度 396 px/s（+20%） |
| 发射间隔 / 子弹速度 | 0.18 s（约 5.5 发/秒）/ 540 px/s |
| 子弹伤害 | 1 / 发 |
| 小型敌机（enemy1） | 原尺寸，生命 1，速度 95~150 px/s，100 分 |
| 中型敌机（enemy2） | 显示尺寸缩小 20%，生命 5，速度 60~95 px/s，500 分 |
| 大型敌机（enemy3） | 显示尺寸缩小 20%，生命 22，速度 28~48 px/s，4000 分 |
| 难度系数 | `1 + min(分数/30000, 1)`，即敌机速度随分数最高提速至 2 倍 |
| 敌机生成间隔 | `max(0.28, 0.75 - min(分数/30000, 1) × 0.47)` 秒 |
| 敌机类型权重 | 开局：小型 ~86.5% / 中型 ~12% / 大型 ~1.5%；随分数增加，中型每 2500 分 +1%（上限 32%）、大型每 8000 分 +1%（上限 9.5%），小型相应回落 |
| 道具掉落 | 击毁敌机 7% 概率；若 25 秒未掉落则下一次必掉；炸弹/火力各 50% |
| 道具下落速度 | 75 px/s（带轻微左右摆动） |
| 双发强化时长 | 30 s |
| 炸弹上限 | 9 颗 |
| 背景滚动 | 49 px/s（原 70，减慢 30%），方向向下（营造向上飞行的纵版感） |

## 技术说明

- **渲染**：HTML5 Canvas，单 `requestAnimationFrame` 循环，按 DPR（最高 2 倍）渲染保证高清屏清晰；页面 CSS 等比缩放居中。
- **音效 / 音乐**：`js/audio.js` 用 Web Audio API 实时合成 —— 背景音乐为循环旋律（三角波主旋律 + 锯齿波低音 + 合成鼓点），爆炸为噪声 + 低频下滑音，按敌机体型区分音量与时长；`AudioContext` 在“开始游戏”点击时创建（符合浏览器自动播放策略）。
- **动画**：主角 `me1/me2` 双帧交替（引擎动态）、大型敌机 `enemy3_n1/n2` 双帧交替；中/大型敌机受击闪烁 `enemy*_hit` 帧；爆炸使用各体型专属多帧序列（小型/中型 4 帧、大型 6 帧、主角 4 帧）。
- **最高分**：localStorage（键名 `plane_game_high`），隐私模式等异常已做容错。
- **兼容性**：无框架、无构建步骤，经典 `<script>` 引入，Chrome / Edge / Firefox 均可运行。

## 文件结构

```
PlaneGame/
├── index.html          # 入口页面
├── style.css           # 页面样式（纸张质感 + 等比缩放）
├── server.js           # 可选本地静态服务器
├── images/             # 手绘素材（39 张 PNG）
└── js/
    ├── assets.js       # 素材加载器
    ├── audio.js        # Web Audio 音效 + 背景音乐
    ├── game.js         # 游戏主逻辑（数值/实体/碰撞/HUD/状态机）
    └── main.js         # 启动入口（DPR 缩放 + 加载画面）
```
